# 示例 | 社区工坊预约提示

[下载示例 HTML](workshop-booking.html)。如果 GitHub 显示源码，使用文件页的下载按钮保存 HTML，再双击文件在浏览器打开。示例使用虚构数据，状态保存在当前页面内存中，关闭或刷新会恢复初始状态。

## 输入需求

> 请做一份虚构的社区工坊预约原型，PC 管理视图可为木工室和陶艺室分别设置预约提示。使用端要让访客切换房间并看到该房间已启用的提示。管理员可以保存、取消和关闭提示。提示启用时文字不能为空。设置重开应回显上次已保存的值。用简体中文，提供可离线打开的单文件 HTML，桌面和窄屏都能操作。

## 手动验收

| 操作 | 预期结果 |
|---|---|
| 在访客视图从木工室切到陶艺室 | 木工室有初始提示，陶艺室无提示 |
| 打开陶艺室设置，启用提示，留空并保存 | 显示必填反馈，弹窗保持打开 |
| 填写并保存，再进入访客视图切换房间 | 陶艺室显示新提示，木工室保持原有提示 |
| 重开陶艺室设置，修改文字后取消 | 回显已保存内容。取消后访客看到的提示保持原值，焦点返回设置按钮 |
| 关闭陶艺室提示并保存 | 访客视图隐藏陶艺室提示 |
| 只保留一个 HTML 并断网，分别以桌面和窄屏尺寸操作 | 页面正常显示，主路径可走通，无横向滚动 |

## 浏览器回归

在仓库根目录运行。需要 Node.js 22.20 或以上版本。Playwright 下载 Chromium，随后在离线浏览器环境中测试本地 HTML。

```sh
npm ci
npx playwright install chromium
npm test
```

测试把示例 HTML 复制到独立空目录，分别在 1440 × 900 和 390 × 844 视口打开，核对校验、保存、房间隔离、回显、取消、Esc、停用和控制台错误。如需使用现有 Chromium，可将环境变量 `CHROME_EXECUTABLE` 指向可执行文件。
